# Joseph's Voice-Typing

**조셉스 보이스 타이핑** · Windows 음성 받아쓰기 앱

## [Windows 설치 ZIP 다운로드](https://github.com/Febrile-JoJoo/Josephs-Voice-Typing/releases/latest)

현재 배포 버전: **0.1.19**

1. 릴리즈의 Assets에서 `Josephs-Voice-Typing-Setup-0.1.19.zip`을 내려받습니다.
2. ZIP의 압축을 풉니다.
3. 안의 `Josephs-Voice-Typing-Setup-0.1.19.exe`를 실행합니다.

Windows 10/11 64비트를 지원하며 Python을 따로 설치할 필요가 없습니다. ZIP에는 설치 EXE 하나만 들어 있습니다. 기존 버전의 독립 EXE 다운로드는 최신 ZIP 배포로 대체합니다.

- 기본 단축키: **F8** — 한 번 누르면 녹음 시작, 다시 누르면 종료
- 음성 인식: 본인의 OpenAI API 키 연결 필요, API 사용료 별도
- 문장 정리에 ChatGPT 구독을 연결하려면 공식 Codex 런타임 별도 필요
- 코드 서명 전으로 Windows의 게시자 확인 경고가 표시될 수 있습니다.

이 저장소는 설치 파일 배포와 설치 안내를 위한 공간입니다. 앱 소스 코드는 포함하지 않습니다. 버전별 변경 사항과 검증 범위는 릴리즈 본문에서 확인하세요.
