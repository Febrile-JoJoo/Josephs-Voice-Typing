# Joseph's Voice-Typing

**조셉스 보이스 타이핑** · Windows 음성 받아쓰기 앱

## [Windows 설치 파일 다운로드](https://github.com/Febrile-JoJoo/Josephs-Voice-Typing/releases/latest)

배포 버전의 Assets에서 `Josephs-Voice-Typing-Setup-버전.exe`를 내려받아 실행하세요.
Windows 10/11 64비트를 지원하며 Python을 따로 설치할 필요가 없습니다.

- 기본 단축키: **F8** — 한 번 누르면 녹음 시작, 다시 누르면 종료
- 음성 인식: 본인의 OpenAI API 키 연결 필요, API 사용료 별도
- 문장 정리에 ChatGPT 구독을 연결하려면 공식 Codex 런타임 별도 필요

이 저장소는 설치 파일 배포와 설치 안내를 위한 공간입니다. 앱 소스 코드는 포함하지 않습니다.
